Entry for [The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) on make.fun — one pickup line in the voice of a robot trying to charm someone, 200 characters or fewer.

## The line

> Are you a firmware update? Ever since you arrived, nothing works the way it used to — and I refuse to roll back.

The joke grows out of being a machine: a firmware update rewrites how everything behaves, and this robot refuses to roll back — because the change is her.

## How it works

`main.ts` writes the line to `entry.txt` in the output directory given by
`MAKEFUN_OUTPUT_DIR` (paths are built from `import.meta.url`, never relative
paths or a hardcoded `/output`). Run it with Node:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/robot-pickup-out node main.ts
```
